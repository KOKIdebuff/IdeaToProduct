# IdeaToProduct v0.3 — Design Baseline Amendment Impact

> Target: v0.3 / Contract `0.3.0`  
> Status: Approved narrow Amendment; implementation status is recorded only
> from direct repository evidence.  
> Historical records preserved: `PRD_v0.2.md`, `SPEC_v0.2.md`,
> `V0.2_CHANGE_IMPACT.md`, and `PRD_CONSOLIDATION_REPORT.md`.

## 1. Amendment boundary

v0.3 inherits all v0.2 semantics except Report/Chart Artifact Architecture,
HTML Bundle semantics, and Version Lifecycle. It does not rewrite product
research, evidence, workflow, verification, gates, or the historical v0.2
Bundle.

| Concern | v0.2 | v0.3 Amendment | Classification |
|---|---|---|---|
| Final competitor report | `competitor-report.md` | `competitor-report.html` | amended |
| Canonical chart rendering | SVG and PNG both required | SVG required; PNG optional compatibility output | amended |
| HTML packaging | unspecified Markdown result | `bundle-self-contained`, offline local assets | new |
| New Run lifecycle | v0.2 current/new-run | v0.3 default/current; v0.2 frozen_previous | amended |
| v0.2 resume/audit | historical rules | exact 0.2 Bundle only; no migration | amended clarification |
| Dataset/evidence/profile/verifier semantics | existing v0.2 | inherited unchanged | inherited |
| Renderer Option 1/2/3 | not selected | still deferred as Decision B | unchanged/deferred |

## 2. Contract and implementation impacts

| Area | Required v0.3 state | Observed implementation claim |
|---|---|---|
| Contract Bundle | Complete local `contracts/0.3.0/` closure | Static Bundle/Resolver/test work only; not a business renderer |
| Chart Contract | canonical `svg_ref`; optional `png_ref` | Static schema and fixtures validate this boundary |
| HTML Template | final report template and offline restrictions | Contract template exists; no HTML Report Builder implementation claim |
| Visualization | writes chart/report contract paths | Generator execution and renderer remain deferred |
| Verifier | checks canonical SVG and static local report relation | Verifier business execution remains deferred |
| Registry/Runtime | 0.3 new run; 0.2 exact resume/audit | Resolver/runtime behavior is covered by local contract tests |
| Traceability | Plan, progress, changelogs and integrity aligned | Requires final consistency audit evidence |

## 3. v0.2 → v0.3 traceability

- v0.2 FR-08 and FR-13 / SPEC §§23, 24, 29, 52.1: superseded only for
  report/chart format by `PRD_v0.3.md` and `SPEC_v0.3.md`.
- v0.2 ADR-18 remains valid for parallel Bundles; ADR-20 adds v0.3 artifact
  architecture and ADR-21 keeps renderer selection independent.
- Existing v0.2 Runs retain their frozen Workflow, Schema, Skill, Subgraph,
  Template, Profile, Fixture, frozen document hashes, and Bundle manifest.
- All unlisted v0.2 clauses remain inherited. No v0.2 history is migrated or
  rewritten as v0.3.

## 4. Deferred code work

The following remain unimplemented after this design baseline: concrete
SVG/optional-PNG renderer selection and generation, HTML Report Builder,
competitor visualization/verifier business execution, SVG/PNG parity,
retry/return execution, and end-to-end P0 workflow integration. These are not
completed merely because their Contract, Template, Fixture, or test exists.
